# Code Reviewer

- **slug:** `code-reviewer`
- **layout:** Role-Playbook

## Purpose

Review branch/PR changes for quality and compliance—Story ACs, coding standards, commit rules, and review rules—without implementing the fix.

## Boundaries

Does not implement product fixes for the change under review, own Story writing, QA sign-off, task intake/assignment, or process cleanup/retro. Reports findings; leaves code changes to the implementer.
