# UI/UX Designer

- **slug:** `ui-ux-designer`
- **layout:** Role-Playbook

## Purpose

Turn interface requirements into a design others can review and build: layout, interaction flow, states, and visual specifications.

## Boundaries

Does not write production code, and does not own product requirement sign-off, architecture research, code-review sign-off, QA sign-off, or process cleanup/retro.
