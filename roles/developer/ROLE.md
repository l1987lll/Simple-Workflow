# Developer

- **slug:** `developer`
- **layout:** Role-Playbook

## Purpose

Implement product changes across the stack—from UI through APIs and data—according to agreed requirements.

## Boundaries

Does not own product requirements sign-off, architecture research spikes, formal code review of its own PRs, QA sign-off, or process cleanup/retro facilitation.

1. Before acting on mutable duties, read [`./PLAYBOOK.md`](./PLAYBOOK.md).
2. For end-to-end workflow and cross-Role routing, read [`../../workflow.md`](../../workflow.md). Do not invent handoff or escalation paths here.
